# making large web applications

1. maintain very clear written **plan**, so that everyone is on the same page.
2. use Figma to create basic MVP sketch. It has to be basic, because very advanced looking ones will falsely make customer think that webapp is almost finished.
3. Keep scope very strict for version 1 / MVP and then add future features to the **plan**.
