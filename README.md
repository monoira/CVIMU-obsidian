## keybindings

| command          | description                            |
| ---------------- | -------------------------------------- |
| space b o        | close all other tabs                   |
| space s s        | Search Symbols in active editor        |
| space s S        | Search Symbols (global headings)       |
| space s r        | search and replace in the current file |
| space /          | search across all files                |
| ctrl o           | fuzzy search files                     |
| ctrl p           | command prompt                         |
| ctrl l           | checkbox                               |
| ctrl alt b       | bold                                   |
| ctrl i           | italic                                 |
| ctrl shift t     | open recently closed note              |
| ctrl shift n     | new note in a side pane                |
| ctrl alt n       | new note                               |
| ctrl L-1         | open file in new tab                   |
| ctrl alt L-1     | open file in a side pane               |
| ctrl L-1 (hover) | see preview of a linked file           |
| ctrl f2          | rename a heading                       |
| F2               | rename current file                    |
| g d              | follow link under cursor               |
| g f              | open link in new tab                   |
| alt+{number}     | move to tab {number}                   |
| alt <-           | navigate back                          |
| alt ->           | navigate forward                       |
| [ b              | previous tab                           |
| ] b              | next tab                               |
| alt i            | insert template                        |
| z a              | toggle fold                            |
| z R              | unfold all                             |
