# learning methods and my note taking system

## concepts

- **JIT** (just-in-time) information can be applied immediately to change your life.
- **JIC** (just-in-case) information is recreational and educational, which might be used in future, but majority of it gets forgotten.
- When trying to learn something, spend first 10% of the time on learning the way, rest on actually learning it by actually doing it.
- 5 minute rule: when procrastinating, just commit 5 minutes to that task without distractions, which has chance of awakening flow state, if it doesn't, choice is yours.

## techniques

### active recall

- Try to recall information you're trying to memorize. Forcing information retrieval of information increases chances of it being memorized.
- Each time you struggle and finally recalled information, you did recall.
- It takes 7 recalls to learn.
- Some use 'question / answer' flash cars for active recall.

### spaced repetition

Learn something, sleep, repeat that thing again.

### summary writing

Write down summaries of what you read, since it forces brain to think about that and therefore remember it.

## my note taking system

1. take a note in a notebook (ideally summaries of what you've read for more brain usage).
2. 1 or more days later, repeat contents of that note in front of the mirror.
3. write notebook notes to Obsidian.
4. throw away notebook note.

This uses mostly spaced repetition, with some active recall.
Its also important to write down **summaries**, don't just copy and paste what you read, higher brain usage = more memorization.

use **bold** for things you want highlightend.
use ticks for file and directory names like `src` or `auth.module.ts`.
use ticks for server URLs like `/v1/users`.
